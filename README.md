# Rizal Aji Purbadinata

Software engineer building digital scoring and championship management systems for **pencak silat**.

### What I work on

- **Real-time judging** — scores pushed over WebSockets to judges' tablets, the referee board, and the audience display, built to keep running on a venue's local network without internet.
- **Championship management** — athlete and team registration, draws and brackets, match schedules, results, and certificates.
- **Performance** — profiling Laravel/Livewire apps in production: N+1 queries, caching, and asset weight.
